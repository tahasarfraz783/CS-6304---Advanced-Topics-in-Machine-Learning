This programming assignment presents four practical investigations into deep-learning models with
different architectural principles and learning objectives. The first task examines
how residual connections, network depth, and ImageNet pretraining affect the
performance and learned representations of convolutional networks. The second
investigates how Vision Transformers classify images through patch embeddings
and self-attention, with particular attention to interpretability, input masking, and
feature pooling. The third studies the multimodal representations learned by
CLIP through zero-shot classification, prompt engineering, visualization of the
image-text modality gap, and orthogonal alignment. The final task evaluates
how Variational Autoencoders learn probabilistic latent representations for image
reconstruction and generation. Together, these experiments provide practical insight
into convolutional, attention-based, multimodal, and probabilistic approaches to
representation learning.
