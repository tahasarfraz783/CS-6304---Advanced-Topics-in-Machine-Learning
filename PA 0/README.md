This report presents four investigations into deep-learning models with different
architectural principles. The first task examines how residual connections, network
depth, and ImageNet pretraining affect the performance and learned representa-
tions of convolutional networks. The second investigates how Vision Transformers
classify images through patch embeddings and self-attention, how masking impor-
tant patches affects predictions, and how classification-token pooling compares
with mean pooling. The third studies the multimodal representations learned by
CLIP through zero-shot classification, prompt engineering, visualization of the
image-text modality gap, and orthogonal alignment. The final task evaluates how
Variational Autoencoders learn probabilistic latent representations for image re-
construction and generation. Together, these experiments compare convolutional,
attention-based, multimodal, and generative approaches to image representation.
